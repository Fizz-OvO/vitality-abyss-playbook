1. 構成コンセプト（ジェット＋ヨル構成）

  • Team Vitality Abyss comp（ジェット＋ヨル構成）
  • Jamppi = Yoru（ヨル）／ Derke = Jett（ジェット）／ PROFEK = Astra（アストラ）／ Chronicle = Harbor（ハーバー）／ Sayonara = Sova（ソーヴァ）
  • 2デュエリスト＋2コントローラー＋1イニシエーター、センチネル不在
  • 相手もピックも異なる3試合すべてで同一構成 ＝ Abyssの「固定構成」として運用されていた
  • 攻撃 17勝12敗（58.6%） ／ 防衛 13勝22敗（37.1%）と、攻防で大きく非対称な構成
  • 数値出典: vlr.gg（勝敗・勝利条件・経済）／ rib.gg 2Dリプレイ（プラント・ファーストブラッド）で検証。プラントのサイトはマップ位置からの推定、FBは2ラウンドがフィード破損で不明

強み

  • 攻撃の取り切り力
  • → 攻撃は17勝12敗（58.6%）。勝った17ラウンドのうち15ラウンドは設置済みで、全滅勝ち14回のうち12回も設置した後の勝ち。設置しなかった勝ちは2回だけで、「設置した上で全滅まで取り切る」攻撃になっている
  • → 両チームともフルバイのラウンドでも8勝4敗（66.7%）と勝ち越し（VITがフルバイの攻撃ラウンド全体では14勝6敗）
  • ファーストブラッドを取った攻撃はほぼ落とさない
  • → 攻撃でFBを取ったラウンドは9勝1敗（90%）
  • → 攻撃でのFB取得はDerke 6回・Jamppi 3回・Chronicle 1回の計10回（攻防合計ではDerke 10回・Jamppi 7回・Chronicle 7回）
  • 設置まで持っていく力
  • → 攻撃29ラウンド中23ラウンド（79%）で設置に成功。サイトはB 14回／A 9回とB寄り（特にGE戦はB6／A3）。ただしサイトはribのマップ位置からの推定
  • 設置担当の固定
  • → 設置23回のうちSayonara（Sova）が15回（65%）と、設置役がほぼ固定されている
  • → SayonaraのFB取得は3試合で1回（防衛のG2戦R16）だけで、序盤の接敵を担わない役割分担が数字にも出ている。設置者の生存率やポストプラントの人数配分は映像で確認する
  • 【推論／映像確認待ち】ダブルコントローラーの制圧力（構成面）
  • → Astraの星とHarborのウォール／コーヴを重ねれば、エントリーの遮断と設置カバー（コーヴで設置役を守る）を両立できるはず
  • → 縦に長いAbyssで視線を何重にも切れるのはこの構成の土台と考えられる。実際のユーティリティの使い方・順序はGIFで確認する
  • 【推論／映像確認待ち】ヨルのテレポートによる圧の付け替え（構成面）
  • → 片サイトで見せてからTPで本命に合流する動きは構成上可能で、相手のローテーション判断を遅らせる狙いが考えられる
  • → TPの使用回数や実際に相手が釣られたかは映像でしか確認できないため、採用頻度はGIF分類後に判断する

弱み

  • 防衛が大きく負け越す
  • → 防衛は13勝22敗（37.1%）。相手の設置を許したのは少なくとも30ラウンド（記録のある範囲で35ラウンド中30ラウンド、86%。G2戦R14は記録なし）
  • → 【推論】センチネル不在でサイトを止めきれないことが一因と考えられるが、実際にどこで崩れたかは映像で確認する。リテイクが決まらない試合（NS戦 防衛4-8、G2戦 防衛4-8）ではそのまま崩れた
  • 防衛はファーストブラッドと勝敗が強く連動する
  • → 防衛でFBを取ったラウンドは10勝5敗だが、FBを落としたラウンドは3勝15敗（FB記録があるのは防衛35ラウンド中33ラウンドで、不明の2ラウンドはいずれも負け）
  • → FBがVIT側の攻めの失敗か相手の攻めによるものかは集計では判別できず、序盤の人数差がどう崩壊につながったかは映像で確認する
  • ポストプラントを守り切れない
  • → 設置した23ラウンドは15勝8敗だが、負けた8ラウンドはすべて解除負け
  • → 逆に爆発まで守り切った勝ちは3回だけで、設置後に時間を使い切る遅延・配置が課題（設置後の立ち位置はGIFで検証予定）
  • 攻撃の入りは負け越し
  • → 攻撃のFBは10―19。ただしFBを取れば9勝1敗、落としても8勝11敗と半分近くは取り返している（取り返し方は映像で確認する）
  • → NS戦は攻撃のFBが1―4（試合全体では4―12）と序盤で後手に回り、攻撃0勝5敗に終わった
  • ピストルは五分
  • → ピストルラウンドは3勝3敗。GE戦は攻撃ピストルと続くラウンドを落として0-2スタートになるなど、ハーフの入りの安定感に欠ける

攻めのデフォルト

  • 基本デフォルト（1-3-1）
  • → A端 1 ／ 中央 3 ／ B端 1。両端にデュエリスト（Yoru／Jett）を1人ずつ置いて圧と情報を取り、中央3人（Sovaのリコン＋Astra／Harbor）がミッドと両リンクを制圧する形
  • → Abyssはミッド経由で両サイトへ速く寄れるため、中央を厚くして「どちらにも行ける」状態を作るのが基本線という想定。選手の実際の初期位置はGIFのバイフェーズで検証する
  • 2-1-2
  • → 両サイト寄せを厚くし、ミッドは1人で情報だけ取る形（担当選手は未確認）
  • → 片側へのヒット転換が速く、相手の薄いサイトを読むラウンド向き
  • 1-2-2
  • → 片端にYoruを単独で残してラーク／フェイクの圧をかけ、本隊は中央＋片サイトに4人
  • → YoruはTPでいつでも本隊に合流できる
  • 3-1-1（サイトグループ型）
  • → 本命サイト側に3人を寄せたヒット準備形
  • → 逆端の1人（Yoru想定）は音とクローンで存在を見せ、実行と同時にTP合流か裏取りを選ぶ
  • 5人集結（ラッシュ型）
  • → デフォルトを挟まず片サイトに一気に当たる形
  • → エコ／アンチエコや、相手の配置を読んだラウンドで使う想定。採用の有無はGIF分類で確認する
  • ※ 攻撃の配置は放送ミニマップの仕様で選手単位の実測ができないため推論のまま。実測できたのはエントリー先（B 14回・8勝6敗／A 9回・7勝2敗）

防衛のデフォルト（実測）

  • 固定形はなし（実測）
  • → vreplayの映像追跡で4人以上を検出できた防衛26ラウンドでは、単一の固定デフォルトは確認できなかった。中心は2-1-2系のバランス形で、Aスタック（Aに3～4人）やB厚め、ミッド厚めも混ざる
  • → 実際、防衛の勝ち13回のうち9回が解除勝ちで、相手の設置を許したのは少なくとも30ラウンドだった
  • 選手のアンカー（実測）
  • → SayonaraはAアンカー（A配置15回）、ChronicleはBアンカー（15回）、JamppiはB寄り（14回）、DerkeはA・B・ミッドを動くフリー、PROFEKはA寄り
  • → センチネル不在の守りは「固定配置で止める」より「アンカー＋寄せ」で対応する形が実測から見える
  • 前線情報型
  • → 早い時間に撃ち合いを取りにいく形という想定。防衛のFB取得は15回（内訳はChronicle 6回・Jamppi 4回・Derke 4回・Sayonara 1回）あり、取ったラウンドは10勝5敗と機能している
  • → ただしG2戦R17のように設置後のリテイク局面でのFBも含まれ、すべてが序盤の接敵とは限らない。落とすと3勝15敗まで崩れる、ハイリスクな選択肢

エクセキューション

  • B寄りエグゼキュート
  • → 設置先は全体でB寄り（B 14回／A 9回。サイトは位置推定）。特にGE戦はB6／A3と偏った
  • → G2戦はB6／A5と均等に近い。ただし設置サイトは最終的に設置した場所であって、エグゼキュートの設計そのものではない
  • ダブルデュエリスト同時エントリー
  • → 【推論／映像確認待ち】JettのダッシュとYoruのゲートクラッシュでサイト内に同時に侵入し、守備側のクロスを崩す形が想定される
  • → 攻撃の全滅勝ち14回のうち12回は設置後の勝ちで、全滅勝ちの多さ自体は同時エントリーの証拠にはならない。同時侵入だったか、どちらが先行したかはGIFで確認する
  • ヨルTPフェイク → 逆サイト合流
  • → 【推論／映像確認待ち】Yoruが片サイトでクローンと足音で存在を見せ、相手のローテーションを引き出してからTPで本命サイトに合流し、数的優位を作る型が想定される
  • → 1-2-2や3-1-1の形とセットで使う想定。実況タグではVIT攻撃の4ラウンドで「フェイク」への言及があった（2勝2敗）が、ヨルTPによるものかは断定できない
  • 実測：ラッシュとULTの取り切り
  • → VIT攻撃ラウンドの勝因集計（vreplay判定）で、「ラッシュ」は5ラウンドあり全勝、「ULTで攻め切り」は8ラウンドあり全勝
  • → 速いヒットとULT合わせのラウンドは落としていない。逆に言えば、スローなデフォルトから崩す形の勝ち筋は別に必要になる

ポストプラント

  • Sayonara設置固定
  • → 設置役をSayonara（Sova）に固定（23回中15回＝65%）。設置役が固定されることで、デュエリスト2人は設置中もサイト周辺の制圧に専念できる形になる
  • → 【映像確認待ち】設置をHarborのコーヴで守るか、Astraの星をポストプラントの遅延用に残すかなど、ユーティリティの使い方と順序はGIFで確認する
  • 戦って守る
  • → 設置後の勝ち15回のうち12回が全滅勝ち／爆発は3回。時間で逃げ切るより、リテイクに来た相手を倒して守る傾向が強い
  • 課題: 解除負け
  • → 設置して負けた8ラウンドはすべて解除負け。爆発まで守り切った勝ちは3回だけで、時間を稼いで守る勝ちが少ない（設置後の立ち位置はGIFでラウンドごとに確認する）
